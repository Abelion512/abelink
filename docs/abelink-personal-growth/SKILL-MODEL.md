# Skill Model

## State Machine

```text
UNKNOWN
  ↓
EXPOSED
  ↓
PRACTICED
  ↓
APPLIED
  ↓
TRANSFERABLE
  ↓
MASTERED
```

A skill may also become:

```text
FRAGILE
```

when evidence shows successful execution in one context but repeated failure to transfer the same fundamental knowledge to changed contexts.

## Evidence Types

- explanation
- quiz
- independent task
- blind transfer
- project artifact
- code review
- research artifact
- real-world outcome

## Update Principle

The skill model should prefer multiple independent pieces of evidence over a single completion event.

## Anti-Cheat Principle

AI completion must not be treated as direct proof of user mastery.
