# Grill-Abelion Reusable Skill

This folder contains the reusable project-discovery interview skill.

## Files

- `SKILL.md`: copy into an Abelink-compatible skill store.

## Usage

Use when the user does not know what project, tool, automation, or workflow should be built.

Grill-Me should interview first, then generate and compare candidates, then produce an implementation-ready specification for the selected project.
