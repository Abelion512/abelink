1. **Kontrak frame jadi tipe di registry.ts**: FrameRequest/FrameResponse/
   FrameEvent; `error: unknown` (bukan string) karena `ai:fetch` mengirim
   objek {message, code} — fakta wire, bukan perubahan.
2. **Modul main/* ber-JSDoc sempit** (inference minim) dianotasi ulang via
   interface lokal + cast `as unknown as` — runtime persis asli. Naikkan
   bertahap saat W5 mengetikkan sidecar/main.
3. **Deklarasi ambient baru** `sidecar/types/untyped-deps.d.ts`: mammoth,
   msedge-tts, yt-search, adm-zip (tidak ada .d.ts; bentuk minimal pemakaian).
4. **TS narrowing**: never-returning guard wajib function declaration
   (`function rejectX(): never`), const-arrow tidak cukup; `isValidSkillName`
   jadi type predicate. Guard komposit `name != null && !pred(name)` tidak
   me-narrow — predikat kedua ditambahkan di cabang pemakaian (murni regex,
   ekuivalen).
5. **prefer-const** menyeret satu `let`->`const` di browser.ts (rule TS ketat;
   tanpa efek perilaku).
6. **Lint warning baru (2)**: `EXTERNAL_SKILL_DIRS`/`scanExternalDir` dead-code
   pra-eksisting di skills.mjs yang baru terlihat karena blok TS melint .ts
   (dulu .mjs tidak dilint). Dibiarkan sebagai tech-debt terdaftar; kandidat
   ponytail-audit terpisah.
7. **Pelajaran proses**: dua kali merge PR (89) sebelum semua required checks
